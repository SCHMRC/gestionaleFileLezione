# 📄 Gestione File in Java

Questo progetto dimostra come leggere, scrivere e modificare un file di testo in Java, utilizzando le classi della libreria standard (`File`, `FileReader`, `FileWriter`, `BufferedReader`, `BufferedWriter`).

---

## 📌 Funzionalità

- ✅ Creazione di un file `.txt` se non esiste
- ✅ Scrittura di testo nel file
- ✅ Lettura del contenuto del file riga per riga
- ✅ Modifica del contenuto (es. sostituzione di parole)

---

## 🛠️ Tecnologie utilizzate

- Linguaggio: **Java 17+**
- IDE suggerito: **Eclipse / VS Code / IntelliJ**
- Strumenti standard: `java.io.*`, `java.util.*`
